# M2D02-D — assembled environment replaces atlas board lab

The earlier M2D02-C source overview was a mistaken interpretation of the mapping-certification workspace. It pasted 29 canonical source atlases on an enormous canvas and reduced the actual test environment to a thumbnail. **This pass replaces that output rather than creating a second user-facing sample scene.**

- Opening Studio now fits a contiguous **72×28 original-source-addressed assembled summer environment**, using the protected 40×28/1,120-tile original River fixture verbatim within it. The remaining grassland is authored source-cell draft scenery and is not labelled validated procedural generation.
- An independent, image-backed object composition pass draws **18 source-referenced complete visual sample regions** (trees and boulders) over the assembled ground. Every source crop is within the canonical hydrated original manifest. These are *draft visual integration samples*, not a claim about approved footprint, collision, navigation, seasons, cliffs, or generator coverage.
- No original atlas is pasted into the world. The 29 original Terrain sheets remain available in the floating Source / Advanced mapping browser. A visible selected whole visual sample can be inspected or removed. Removal and terrain-cell edits are undoable and persist in `content/scenes/derived/elizawy_mapping_certification.assembled.draft.json`.
- The former `content/scenes/derived/elizawy_mapping_certification.draft.json` from C is **left untouched**, even if edited locally. This is not an automatic format migration; converting corrections from the old board document requires a separate explicit import. Rebuilding source scene/index also leaves both derived draft paths untouched. Git ignores `content/scenes/derived/` and the standard ForgePY source-only packager excludes local derived drafts; promotion of a reviewed scene will require an explicit future action.
- A v2 preview refuses scenes with hidden-object IDs until a lossless v2 object migration is implemented. It must not silently discard removed-instance records.
- Source evidence (305 Summer non-transparent original cells) and DG terrain-rule certification (0/16) stay distinct. The index separately reports how many source tiles actually appear in this assembled scene. Only **51 distinct original Summer terrain source cells** appear on this current assembled canvas. The scene does **not** pretend that all 305 source cells or 29 Terrain sheets have been visually exercised.
- The old original Summer River scene is retained as a regression fixture only. No ElizaWy assets, historical evidence, alternate-season artwork, terrain rules, Cargo lock or character art are modified by this patch.

## End-user acceptance

Run the PCC full gate; launch Studio DX12. It should display **one assembled landscape rather than a collage**. Test Fit, selected boulder → Remove object, Undo, Redo, Save Scene, close/reopen and check that the boulder remains removed. Select a terrain cell, use Source Browser to sample a replacement cell, Paint, Save and reopen. The source atlas should be unaffected. Confirm existing old mapping-board draft still has its prior filename and content. Review any tree/boulder crop and report a source-footprint error instead of certifying it automatically.

This is an assembled mapping **visual integration** baseline, not a complete game scene generator. More complex, source-exact cliff/elevation/waterfall recipes will be introduced after their real assembly and runtime/editor parity are verified. Regenerate remains disabled until a manual-override-aware generator exists.
