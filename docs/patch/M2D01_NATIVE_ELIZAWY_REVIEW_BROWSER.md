# M2D01 — Native ElizaWy evidence review browser

**Base**: user's 2026-09-27 source-only archive after M2C4; Havenwild Bevy source 0.5.6, ForgePY 0.4.6, PCC 1.2.6. This is one focused root-drop PCC update. It is **not** a new runtime or certified terrain-recipe release.

The native Terrain Mapper retains its dockable left/right/bottom/floating surface. A second `ElizaWy Review` tab reads `.forgepy/recovered_mapping/elizawy_tiled_review_registry.v1.json` (created on the user's development workstation by the successful M2C4 exporter). A background thread parses and validates the 10,104 occupied derivative records; a malformed/missing registry shows a visible explanation without blocking Studio startup. Reload is explicit and read-only.

The browser shows original atlas candidate thumbnails from the already hydrated original ElizaWy sheets, all four external seasons, filter/search across unique, ambiguous and unmatched matches, historical Summer group/role hints clearly marked non-certifying, and external Tiled Wang/collision/animation metadata clearly marked evidence-only. It flags the incomplete Autumn `-old.tsx` and Winter numeric-ID/material-name divergence. The original `winter_ice` source remains distinct, never inferred from the derivative's four TSX files. Selecting `Locate in source / DG editor` switches to the established source picker with the exact original atlas cell selected; this DOES NOT assign/certify a recipe. The separate existing recipe controls still own draft edits, undo/redo, Save and manual review status. The currently narrow 16-mask Grass/Void recipe stays unchanged (0/16 certified at handoff).

Local workspace layout persists the selected mapper tab in the same versioned editor-layout document using a serde default; pre-existing layout files deserialize without losing the user's docking state. UI uses virtualized row scrolling, retains the central canvas, does not load the third-party derivative PNG or ZIP into the runtime, and never writes evidence registry or source art.

Patch files are `src/main.rs`, `src/editor_layout.rs`, new `src/elizawy_review.rs`, `tools/rust_source_audit.py`, and this note. No `Cargo.toml`/`Cargo.lock` changes. No source art, scene, game runtime resolver, PCC controller, or external derivative archive included.

Inspect Autumn and Winter warnings; use Locate to select original source and return to the DG Recipe tab. Confirm no mapping certification occurs from browsing.
