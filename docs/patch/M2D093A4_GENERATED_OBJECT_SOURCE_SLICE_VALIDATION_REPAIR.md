# M2D093A4 — Generated object source-slice validation repair

Source transition: **0.10.4 -> 0.10.5**. ForgePY remains **0.4.10** and PCC remains **1.3.5**.

The 0.10.4 Windows Full Gate proved the seasonal crop path itself, then exposed a second validation boundary: Generated World object parts were still required to be exact canonical bindings even after immutable-alpha certification intentionally tightened tree/rock atlas slots to contained source slices. This caused 16 world-document tests to fail on valid Spring/Autumn tree crops.

0.10.5 changes only generated-object part validation to use the existing fail-closed `contains_source_slice()` authority. Terrain cells, authored overrides, reusable behavior profiles, and generation corrections retain exact-binding validation. No source pixels, terrain recipes, worldgen intent, collision, placement, or object-bound calculations change.
